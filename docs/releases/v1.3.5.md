# LocalChat v1.3.5

## 中文

### 更新亮点

- **修复 Windows 10013 启动失败**：UDP `45871` 不可用时自动尝试 `45872-45875`、`59641-59645` 和 `61071-61075`，所有发现端口失败时仍保留手动 IP 连接和本地 HTTP 传输能力。
- **增强同网发现**：针对多网卡、VPN 和虚拟网卡环境，通过活动私网 IPv4 网卡分别广播，并按来源端口回复发现请求。
- **一键修复防火墙**：网络诊断页可检查当前程序的 Windows 入站规则，经用户确认 UAC 后添加仅限本地子网的 UDP/TCP 规则。
- **新增诊断日志**：记录启动阶段、端口绑定、网卡、发现和防火墙结果，支持复制诊断摘要、导出日志和打开日志目录。
- **修复 Windows 身份初始化卡住**：当 Windows DPAPI 无法解密或安全存储缺失旧身份密钥时，不再停在“身份初始化中”；可恢复旧明文密钥时自动重新迁移，否则重置本机身份并提示重新配对。
- **修复手动连接配对显示**：手动 IP 连接后收到配对请求时，会自动切换到请求设备并显示聊天内嵌配对卡片。

## English

### Highlights

- **Fixed Windows error 10013 startup failures**: when UDP `45871` is unavailable, LocalChat tries `45872-45875`, `59641-59645`, and `61071-61075`; manual IP connections and the local HTTP transport remain available if discovery cannot start.
- **More reliable same-network discovery**: broadcasts through active private IPv4 interfaces and replies to the source port, improving behavior with multiple adapters, VPNs, and virtual adapters.
- **One-click firewall repair**: Network Diagnostics checks rules for the current executable and, after a user-approved UAC prompt, adds local-subnet-only UDP/TCP inbound rules.
- **Diagnostic logging**: records startup stages, port binding, adapters, discovery, and firewall results, with summary copy, log export, and log-folder access.
- **Fixed Windows identity initialization stalls**: LocalChat no longer gets stuck when Windows cannot decrypt or no longer has saved identity keys; it re-migrates recoverable legacy keys or resets the local identity and asks users to pair devices again.
- **Fixed manual pairing visibility**: incoming pairing requests after manual IP connection now switch to the requesting device so the inline pairing card is visible.
